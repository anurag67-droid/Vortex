Low-Level Systems Architecture

Asynchronous Multiplexing

One thread watches thousands of non-blocking sockets with Linux epoll. EPOLLONESHOT hands each ready connection to exactly one worker at a time.

Worker Thread Pool

Workers never block on a socket: when a client is slow, the connection goes back to epoll and the worker moves on to someone else.

Zero-Copy File Transfer

Files are sent with sendfile(), so their bytes go from the kernel page cache to the socket without being copied into the server's memory.
